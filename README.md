# Student Performance Analysis 📊

## About the Project
A beginner-friendly data analysis project using Python to explore student academic performance, calculate statistics, and visualize grade patterns.

## Datasets

### 1. Sample Dataset
An initial practice analysis using fictional student marks.

### 2. Real Dataset
Analysis of the UCI Student Performance dataset, focusing on Portuguese language grades and exploring relationships between earlier grades, final grades, and study-time categories.

**Dataset source:** [UCI Student Performance Dataset](https://archive.ics.uci.edu/dataset/320/student%2Bperformance)

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Analysis Performed
- Dataset inspection and data-quality checks
- Final-grade distribution
- Summary statistics
- Comparison of earlier grades with final grades
- Average final grades by sex and study-time category
- Correlation analysis

## Project Files
| File | Description |
|---|---|
| `Student_Performance_Analysis.ipynb` | Initial analysis using fictional sample data |
| `Student_Performance_Analysis_Real_Dataset.ipynb` | Analysis using the UCI dataset |

## Key Learning Outcomes
- Data loading and inspection with Pandas
- Basic data cleaning and validation
- Statistical summaries and grouping
- Data visualization using Matplotlib
- Interpreting correlations and observational data carefully

## Note
The analysis explores associations in the dataset; it does not establish that any single factor causes higher or lower grades.
