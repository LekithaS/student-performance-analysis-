# Student Performance Analysis 📊

## About the Project
This beginner-friendly data analysis project explores student marks in Maths, Science, and English using Python.

## Objectives
- Calculate average marks for each subject.
- Compare individual student performance.
- Identify the highest and lowest student averages.
- Visualize marks using bar charts.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Project Workflow
1. Create a sample dataset.
2. Calculate subject-wise and student-wise averages.
3. Visualize average marks by subject.
4. Compare students' marks using a bar chart.
5. Summarize observations from the results.

## Key Findings
- Science has the highest average marks in this sample dataset.
- Student F has the highest average across the three subjects.
- Student G has the lowest average across the three subjects.

## How to Run
1. Open the `.ipynb` notebook in this repository.
2. Click **Open in Colab** if available, or download the notebook and upload it to [Google Colab](https://colab.research.google.com/).
3. Run the cells from top to bottom.

## Note
The dataset contains sample data created for learning purposes. It does not represent real student records.
